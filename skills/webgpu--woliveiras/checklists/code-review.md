# Code review

- [ ] Confirm architecture and framework ownership are preserved.
- [ ] Trace CPU bytes through WGSL structs/bindings to output attachments.
- [ ] Check feature/limit gates, usages, formats, sample counts, and load/store ops.
- [ ] Check async diagnostics, error scopes, device loss, and initialization failure.
- [ ] Check resize, color/alpha, lifetime, destruction, fallback, and tests.
- [ ] Reject invented API, unjustified casts, and unmeasured optimization claims.
