# Code review

- [ ] Preserve framework renderer/state ownership and supported extension points.
- [ ] Check GLSL ES version, compile/link logs, locations, precision, and interfaces.
- [ ] Trace all pass state, active texture units, pixel store, masks, and bindings.
- [ ] Check buffer bounds, texture/FBO completeness, extensions, resize, and fallback.
- [ ] Check context loss/restore, CPU descriptors, deletion, and tests.
- [ ] Reject invented enums/extensions, state leakage, casts, and unsupported claims.
